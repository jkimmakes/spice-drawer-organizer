# Modular Spice Drawer Organizer v0.1.0

Continuous curved cradles for Ball 4 oz regular-mouth Quilted Crystal jars,
split into printable panels with drop-in X3/Y4 joining keys. The completed
example holds forty jars in a 5×8 grid.

Choose a ready-to-print ZIP:

- **spice-drawer-tested-5x8-v0.1.0.zip** preserves the exact six panels from the
  completed drawer, including the R2 front-left panel and smooth R4 remaining
  panels. It includes all eighteen current keys in one print plate.
- **spice-drawer-universal-5x8-v0.1.0.zip** uses smooth R4 modules with female
  sockets on every edge, eighteen joining keys and twenty-six perimeter plugs.
- **spice-drawer-drawer-specific-5x8-v0.1.0.zip** generates all six smooth R4
  panels with solid outside edges. It needs eighteen joining keys and no plugs.
- **spice-drawer-single-module-v0.1.0.zip** supplies a universal 1×1 module and
  four edge plugs for a smaller fit trial.

Every ZIP contains its print quantities, connector plates, assembly map,
checksums and verification report. Print connector plates instead of the
corresponding individual connector quantities. No printer G-code is included.

The source adds a layout generator for drawer width/depth, printer bed size,
grid counts, module limits and universal or drawer-specific edges. It emits
STLs and splits connector quantities across bed-sized plates. The jar profile
and packing pitch are fixed to the tested Ball jar geometry in this release.

The release passed five planner tests spanning 220 grid/track combinations
and 486 CAD checks across the four packaged configurations, plus mesh and
archive checks. The completed mixed R2/R4 drawer has been physically tried;
new generated configurations still need a fit trial with your printer and jars.

All three project photographs show the actual printed organizer and appear in
the README and assembly guide. The source and profile data build independently
of the original development workspace.
